# Timbre

Aplicação web para gerenciamento de cifras para missas católicas.

## 🚀 Hospedagem

Esta aplicação está configurada para deploy automático no **GitHub Pages**.

**URL da aplicação:** https://fernandofhs.github.io/timbre/

### Como ativar o GitHub Pages:

1. Vá em **Settings** do repositório no GitHub
2. Clique em **Pages** no menu lateral
3. Em **Source**, selecione **GitHub Actions**
4. A aplicação será publicada automaticamente a cada push na branch `main`

Para mais detalhes sobre hospedagem, veja [HOSTING-GITHUB.md](./HOSTING-GITHUB.md)

## 📋 Desenvolvimento

```bash
# Instalar dependências
npm install

# Executar em modo desenvolvimento
npm start

# Build para produção
npm run build

# Executar testes
npm test
```

## 🎵 Funcionalidades

- Gerenciamento de cifras musicais
- Organização por categorias (Entrada, Ofertório, Comunhão, etc.)
- Criação e edição de playlists
- Interface intuitiva para músicos

## 🛠 Tecnologias

- Angular 18
- Angular Material
- TypeScript
- NX Monorepo
- GitHub Pages (hospedagem)
